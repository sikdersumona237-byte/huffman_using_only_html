5. Receiver decodes with the tree

Start at the top. Read one bit at a time: 0 goes left, 1 goes right. When you land on a letter, write it down and go back to the top.

Be honest about security. Huffman coding is compression, not encryption. The tree is the only "key", and it is built from the message itself, so you must share it with the receiver. Anyone who gets both the bits and the tree can read the message. For real secrecy, encrypt the message (for example with AES) and then compress, or use both together.
